# CRIMORA
This public repository contains the complete source code for CRIMORA (Crime Record &amp; Investigation Management System). Built with HTML5, CSS3, and Vanilla JS, it features a secure dashboard for FIR management, network mapping, and analytics. The prototype is fully configured and successfully deployed exclusively on the Zoho Catalyst cloud platform.
Prototype Brief
Project Name: CRIMORA - Crime Record & Investigation Management System

Problem Statement Addressed:
Traditional law enforcement and intelligence agencies often rely on scattered, paper-based records or outdated software. This makes real-time crime pattern analysis, FIR management, and tracking complex criminal networks slow, inefficient, and prone to data silos.

Key Features and Functionalities:

Secure Authentication: Encrypted admin gateway for authorized personnel.

Centralized Intelligence Dashboard: Real-time statistics on active cases, total FIRs, and AI risk scores.

Digital FIR Management: Secure digital ledger for recording and updating First Information Reports.

Jurisdiction & Personnel Directory: Organized modules to track police stations and active officers.

Criminal Network Visualization: Dedicated interface to map connections between suspects, syndicates, and evidence.

Automated Analytics & Reports: Visual crime trends and system-generated PDF reports for monthly reviews.

Technology Stack Used:

Frontend: HTML5, CSS3, Vanilla JavaScript (Dark Theme UI)

Deployment & Hosting: Zoho Catalyst (Web Client Hosting)

Backend & Database: Zoho Catalyst Serverless Functions (Node.js) & Catalyst Data Store

Proposed Impact and Use Case:
CRIMORA acts as a centralized, high-speed digital workspace for police departments. It drastically reduces administrative delays, allows officers to identify crime patterns faster, and ensures sensitive law enforcement data is securely managed on a unified cloud platform.
